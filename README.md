Racentral

Racentral is a mobile app that centralises motorsport data across multiple series, allowing users to personalise their experience and view upcoming events, calendars, and standings in one place.

Features
User authentication (login & registration)
Select preferred motorsport series (F1, WEC, MotoGP, NASCAR, IndyCar)
View next upcoming event across all selected series
Full event calendars for each series
Championship standings
Real-time countdown timer

Run the application using expo go.
